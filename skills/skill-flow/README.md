# skill-flow

**One installable Skill that turns recurring work into a structured, reusable Agent Skill.**

Copy this folder into your Agent’s skills directory → talk → get a compiled `SKILL.md` (and `skill-flow.json` when files can be written).

## Install

Copy the entire `skill-flow` directory (keep `SKILL.md`, `schema/`, `examples/`, `reference/` together).

## Try it

> 请按照流程化创建 skill，我的需求是：每周按区域汇总经营数据并写出周报

## What’s inside

| Path | Role |
| --- | --- |
| `SKILL.md` | The skill agents load |
| `schema/` | Draft JSON shape |
| `examples/` | Golden compile fixture |
| `reference/compile-and-gates.md` | Compile + gate rules |

See the [root README](../../README.md) for what skill-flow does, when to use it, and how to install it.
