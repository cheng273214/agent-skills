# 经营周报

## 何时启用
经营周报、周报数据、本周汇总，或要按区域出周报

## 禁止
不得编造工具未返回的数字；无权限或空结果时停止

## 输入
- 区域（文本，必填） 样例文本：华东

## 步骤
1. 【收集】收集区域：向用户确认区域；收集：区域；等待用户输入后再继续
2. 【调用】查询经营数据：按区域读取本周经营数据；工具：经营数据 / 查询周报
3. 【处理】汇总：按区域汇总销售额与异常；自由度：中
4. 【生成】写周报：模板：区域、本周要点、异常项
5. 【校验】核对数字：每个数字都能回溯到工具返回

## 输出
- 周报（文本）：含区域、本周要点和异常项

## 失败处理
缺权限或空结果时说明原因并停止，不编造数字

## 完成标准
向用户交付周报正文
